ProEQ project documentation :
- 1 Arduino
- 2 11 poles 1 throw rotary switch
- 2 IS31FL3743A I2C Led drivers
- 270 LEDs
- 10 MCP23s017 SPI expander
- 18 ACE absolute encoder
- 15 mechnical switch
- 1 LCD screen 16x02

Global connections :
Arduino <-SPI-> MCP23s17 (x10) <-PORT_CONNECTION- ACE Absolute encoder (x18)
Arduino <-SPI-> MCP23s17 (x10) <-PORT_CONNECTION- Mechanical Switch (x15)
Arduino <-I2C-> IS31FL3743A (x2) -PWM-> LEDS (x270)
Arduino <-LCD_Con-> LCD (x1)
Arduino <-Analog_Input- 11_positions_switch_resistor_ladder (x2)

MCP23s17 addressing register :
Device OPcode : 0100 A2 A1 A0 Read/Write

// SPI MCP defines registers
#define IOCON 0x0A
#define IOCON_parameters 0b01111000   //BANK = 0, Address pin used see page 21

#define IODIRA 0x00
#define IODIRB 0x01
#define IODIR_parameters 0xFF  //0xFF -> everything as input

#define IPOLA 0x02
#define IPOLB 0x03
#define IPOL_parameters 0x00  // polarity = normal

#define GPINTENA 0x04
#define GPINTENB 0x05
#define GPINTEN_parameters 0x00    //disbale interrupt on change

#define GPPUA 0x0C
#define GPPUB 0x0D
#define GPPU_parameters 0x00   //pullup disabled
