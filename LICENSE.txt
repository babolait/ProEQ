ProEQ hardware licence
======================

The hardware design files in this repository (KiCad projects, symbol and
footprint libraries, BOM/assembly data, mechanical and CAD deliverables) are
licensed under the CERN Open Hardware Licence Version 2 - Weakly Reciprocal
(CERN-OHL-W-2.0). The full licence text is in the file `LICENSE` at the root of
this repository.

The firmware in `firmware/` is licensed separately under the MIT licence; see
`firmware/LICENSE`.

The upstream URL for the CERN-OHL-W-2.0 text used here is:
https://gitlab.com/ohwr/project/cernohl/-/wikis/uploads/82b567f43ce515395f7ddbfbad7a8806/cern_ohl_w_v2.txt

This file used to contain the SIL Open Font License of the Recursive font
(a Nerd Fonts release readme/licence pair) which had nothing to do with this
project. That text was not project material and was moved aside on
2026-11-01 to /tmp/proeq-font-debris/ before this file was rewritten.
